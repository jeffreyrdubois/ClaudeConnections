# 🌱 Welcome to your garden

This is your self-hosted markdown garden, running on your own server.

Everything here is a plain `.md` file in the `space/` folder. The same files are:

- **Edited** here in [SilverBullet](https://silverbullet.md) (port `4000`).
- **Published** read-only on the public garden (port `4001`).
- **Read & written by Claude** through the MCP server (port `3004`).

## Try it out

- Create a `[[New Page]]` by typing double brackets — wiki links autocomplete.
- Hit `Cmd/Ctrl-/` for the command palette.
- Run **Show Global Graph** to see the network map of your notes (after enabling
  the Graph View plug — see the project README).
